# WebRTC P2P Video Call Application

A peer-to-peer video calling web application built with WebRTC, Socket.io, React, and Express.

## Project Structure

- `client/`: React frontend application
- `server/`: Express and Socket.io signaling server

## Quick Start

### 1. Start the Server
```bash
cd server
npm install
npm start
```
The signaling server will start on `http://localhost:8000`.

### 2. Start the Client
```bash
cd client
npm install
npm start
```
The React app will start on `http://localhost:3000`.
